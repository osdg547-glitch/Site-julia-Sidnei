# Imagens da página intercambio.html

Suba aqui as fotos para os 3 blocos de destino que ainda estão com placeholder.

## Arquivos esperados (nomes exatos)

| Arquivo | Bloco | Sugestão de imagem |
|---|---|---|
| `oceania.jpg` | Oceania | Caravela-portuguesa / Sydney Opera House / Uluru / Grande Barreira de Coral |
| `america-sul.jpg` | América do Sul | Machu Picchu / Salar de Uyuni / Cartagena |

## Especificações técnicas

- **Formato**: JPG (preferencialmente) ou WebP
- **Proporção**: 4:3 ou 3:2 (paisagem)
- **Resolução mínima**: 1200 × 900 px
- **Resolução ideal**: 1600 × 1200 px
- **Peso**: até 400 KB por foto (otimize antes de subir)

## Como subir pelo GitHub

1. Entre nesta pasta no GitHub
2. **Add file → Upload files**
3. Arraste as 3 fotos com os nomes exatos da tabela acima
4. Commit direto na branch `main`

Assim que estiverem aqui, o `intercambio.html` já vai referenciá-las automaticamente.
